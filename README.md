# CRT Frontend Development

A collection of frontend development practice projects completed during CRT training, covering HTML, CSS, JavaScript, DOM manipulation, and React with Vite.

## About the Project

This repository contains daily practice work and mini-projects created while learning frontend development. It includes forms, webpage layouts, UI clones, a personal portfolio, JavaScript exercises, DOM manipulation, and a React Todo application.

## Tech Stack

- **HTML5** — Page structure and forms
- **CSS3** — Styling, layouts, and responsive design
- **JavaScript** — Programming fundamentals and DOM manipulation
- **React.js** — Component-based user interfaces
- **Vite** — Development server and build tool
- **Git & GitHub** — Version control and project hosting

## Features and Learning Outcomes

- Creating structured webpages using HTML.
- Styling layouts and forms using CSS.
- Practising JavaScript conditions, loops, and DOM manipulation.
- Working with external APIs using Fetch.
- Building React applications with components and state.
- Implementing Todo functionality such as adding, editing, deleting, filtering, and completing tasks.
- Organizing projects using Git and GitHub.

## Run the React Projects

Make sure Node.js and npm are installed.

Navigate to the required project directory:

```bash
cd Day_7/ToDo
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal.

The same commands can be used for the React project in `Day_6/React_App`.
